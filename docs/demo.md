# 演示脚本

录制 60–90 秒的 GIF / 短视频用这份脚本，顺序照抄即可。

> **隐私提醒**：真实模式会打印你账号绑定的门店名（例如「麦当劳××天安数码城得来速餐厅」）和配送地址所在城市。如果介意，**录视频时全程加 `--mock`**，效果一样但不会暴露位置；或者录完把门店名打码。

## 准备

```bash
cd mcd-meeting-butler
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python tools/setup_token.py          # 粘贴一次 Token，输入不回显
```

## 镜头 1｜先证明真连上了（8 秒）

```bash
python -m src.main probe
```

画面停在工具列表上，让观众看到 `mcd-mcp v1.0.0` 真实返回了 **35 个 Tool**。

**旁白**：「这不是本地假数据，是麦当劳官方 MCP 真实返回的工具清单。」

## 镜头 2｜一句话出方案（25 秒）

```bash
python -m src.main plan \
  --people 8 --budget 40 \
  --start "2026-10-24 18:00" \
  --avoid 牛肉,花生 \
  --need-coffee
```

画面依次出现真实调用：

```
→ delivery-query-addresses 取配送地址 ...
→ delivery-query-stores 找门店（beType=6）...
  门店：麦当劳××天安数码城得来速餐厅（storeCode=1990597）
  预约时段：2026-10-24 18:00　会议时间落在门店「下午茶」时段（16:00–18:29）
→ query-meal-assistance 查助餐服务 ...
  · 保鲜速达：可用
  · 专人分餐：可用
  · 专人摆台：可用
  已选：专人摆台
→ query-meals 拉菜单 ...
  分类 5 个，餐品 48 项
→ list-nutrition-foods 拉营养 ...
  营养表 158 条，匹配 28 项
→ calculate-price 官方计价 ...
  原价 ¥310.80 → 实付 ¥308.00（省 ¥2.80）
```

**旁白**（这段是重点，别省）：「注意第三段——它先查了助餐服务。团餐有三档：保鲜速达、专人分餐、专人摆台，后两档要提前四小时预约。现在离会议还有五小时，所以摆台可用；如果是临时会议，它会告诉你差多久。」

## 镜头 3｜结果（20 秒）

```
■ 下午场 · 8 人 · 人均预算 ¥40
  门店：麦当劳××天安数码城得来速餐厅
  预约：2026-10-24 18:00
  助餐：专人摆台
  每人一份：
    · 麦香鸡                ¥18.0  369 kcal
    · 麦咖啡™美式             ¥19.0
  人均 ¥37.0 / 369 kcal
  合计 ¥308.00（预算 ¥320.00）
  ! 人均 369 kcal 低于该时段下限 400，可再加一份小食或饮品
  已按忌口剔除 11 项
```

**旁白**：「人均 37 块，在预算内。重点是最后一行——两个人不吃牛肉、一个人花生过敏，所以带牛肉标签的 11 个品项被直接剔除了，不是『建议少吃』，是根本不会出现在候选里。」

## 镜头 4｜临时会议的反差（10 秒，很出效果）

```bash
python -m src.main plan --people 6 --budget 35 --start "2026-10-24 15:30" --avoid 牛肉
```

输出里会多一行：

```
! 距会议不足 4 小时，专人分餐/摆台已不可预约；提前 4 小时以上下单可解锁摆台服务
```

**旁白**：「同一个工具，会议时间不同，建议就不同。这是查了真实门店的助餐服务状态才有的结论。」

## 镜头 5｜打开 Excel（25 秒）

打开生成的 `点餐方案.xlsx`，依次切四个 Sheet：

1. **点餐总表** —— 发群里就这张，顶部带门店、预约时段、助餐服务
2. **分摊账单** —— AA 到分，尾差归最后一位
3. **营养汇总** —— 人均热量对比区间
4. **省钱明细** —— 官方计价的原价 / 优惠 / 实付

**旁白**：「报销要凭据，分摊要明细。所以最终交付物是这张表，不是一段聊天记录。」
